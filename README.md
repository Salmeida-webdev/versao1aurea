# Áurea Estética — Landing Page Premium

Landing page premium desenvolvida para uma clínica de estética avançada, com foco em sofisticação, naturalidade, experiência premium e alta conversão.

---

## ✨ Sobre o Projeto

A Áurea Estética é uma landing page institucional criada para transmitir:

- elegância visual;
- autoridade estética;
- experiência premium;
- confiança e acolhimento;
- alta percepção de valor.

O projeto foi desenvolvido com foco em:

- performance;
- SEO técnico;
- responsividade premium;
- UX refinada;
- visual cinematográfico;
- carregamento rápido;
- microinterações suaves;
- estrutura profissional.
